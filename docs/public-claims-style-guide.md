# Public Claims Style Guide

## Recommended framing

Use disciplined category language:

- "public architecture thesis"
- "citable category reference"
- "agentic AI infrastructure"
- "evidence-bound action acceptance"
- "before impact"
- "acceptance boundary"
- "verifier-ready evidence"

## Canonical one-sentence definition

**The Acceptance Plane is an architectural function that determines whether a specific autonomous AI action should be accepted by a protected system before impact, based on current, scope-bound, verifier-ready evidence at the acceptance boundary.**

## Short category line

**The Acceptance Plane decides whether an autonomous AI action becomes a real-world consequence.**

## Strong but safe positioning

- "MVG is publishing a public architecture thesis for the Acceptance Plane."
- "The Acceptance Plane names the architectural function that decides whether an autonomous AI action should affect a protected system."
- "Access is not authority. Permission is not proof. Execution is not acceptance."

## Avoid

- "first ever in the world"
- "guaranteed compliance"
- "patent-protected mechanism"
- "formal standard"
- "complete solution"
- "prevents all harmful AI actions"
- "implementation disclosed"

## Preferred replacement language

Instead of "we invented the first Acceptance Plane," use:

> "MVG is publishing a public architecture thesis defining the Acceptance Plane for agentic AI infrastructure."

Instead of "this proves patent priority," use:

> "This creates a public, citable, timestamped category reference."
