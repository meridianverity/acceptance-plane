# Strategic Disclosure Boundary

This repository is intended to publish a category reference and bounded public-evaluation proof chain, not a private commercialization package.

## Safe to publish here

- public architecture thesis language;
- deterministic synthetic scenario vectors;
- ACCEPT / HOLD / REFUSE public-eval outcomes;
- public-eval receipt digest profile;
- public-eval Ed25519 proof receipt;
- public-eval Merkle transparency bundle;
- independent recomputation for reviewer trust;
- shape-only OPA, Envoy, and Kubernetes adapter examples;
- release integrity metadata and SHA256 manifests.

## Keep out of this public repository

- claim charts;
- evidence-of-use material;
- licensing term sheets;
- customer or partner-specific deployment maps;
- private rails, wallet, payment, PSP, or regulated workflow details;
- production API keys, production trust roots, production certificates, or private signing material;
- confidential implementation mechanisms;
- legal opinions or patentability analysis.

## Public release principle

Publish enough to let reviewers verify the category, proof posture, and archive integrity. Do not publish materials whose main value is private enforcement, licensing, commercial negotiation, or claim construction.
