# Contributing

This repository is maintained as a canonical public architecture thesis and source/provenance package for the Acceptance Plane in agentic AI infrastructure.

The v1.0.0 release is intended to remain a stable historical reference. Suggested corrections may be considered for future versions, but changes should preserve the public-safe boundary of the release.

Please do not contribute:

- exact API schemas;
- full evidence object models;
- cryptographic binding methods;
- enforcement pipeline details;
- hardware-specific claim maps;
- partner-specific architectures;
- unpublished patent claim language;
- confidential or proprietary mechanisms.

The guiding principle is:

> Publish the category. Protect the mechanism.
