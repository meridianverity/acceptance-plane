# Security Policy

This repository contains public architecture thesis materials and provenance files for the Acceptance Plane. It is not a product software repository, implementation repository, support forum, vulnerability disclosure program, compliance certification, or standardization venue.

Do not submit confidential information, partner-specific architecture, unpublished patent material, exploit details, credentials, private data, proprietary mechanisms, or implementation-specific evidence models to this repository.

For private or sensitive matters, contact Meridian Verity Group through its official channels rather than opening a public issue or pull request.
