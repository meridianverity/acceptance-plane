# Public Release Title and Description — v1.0.2-public-eval

## Release title

**Acceptance Plane v1.0.2-public-eval — Verifiable Action Acceptance Before Impact**

## One-line description

Fresh-archive-verifiable public-eval proof overlay for deciding whether autonomous AI actions should become protected real-world consequences before impact.

## Short description

The Acceptance Plane defines the architectural function that evaluates current, scope-bound, verifier-ready evidence before an autonomous AI action is accepted by a protected system. This v1.0.2 public-eval release adds a runnable proof chain: 64 deterministic ACCEPT/HOLD/REFUSE vectors, deterministic receipt digests, an Ed25519-signed public-eval proof receipt, a signed Merkle transparency bundle, independent recomputation, scenario-card linting, schema checks, and source/archive verification.

## Reviewer description

This release is built to be verified from a fresh clone or fresh ZIP archive. Reviewers can run `make qa-full` to validate the manifest, public-eval vectors, transparency bundle, proof receipt, independent recomputation, schema examples, release gate, and source-tree verification. With the release ZIP and SHA256 sidecar, reviewers can additionally verify archive integrity and bind the proof receipt to the published archive.

## Strict scope line

Public architecture thesis and bounded public-evaluation proof overlay only. Not a formal standard, product implementation, legal opinion, compliance certification, patent claim chart, patent license, production trust root, deployment guarantee, or complete security solution.
